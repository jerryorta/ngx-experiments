NgeCalendar

Reusable, themeable, theme-agnostic calendar library (@nge/calendar). The <nge-calendar> shell hosts four views behind one config, and every view authors its own story set on the harness this page previews. The swatches below are the theming bridge each view renders through.

Theme tokens

Each swatch reads a --nge-calendar-* token with a literal fallback, so it renders with no host theme and updates live when you switch the theme in the toolbar.
