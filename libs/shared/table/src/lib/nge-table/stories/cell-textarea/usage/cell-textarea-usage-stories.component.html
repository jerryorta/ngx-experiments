NgeTable — Cell Textarea Usage

A column names <nge-cell-textarea> and the table renders it — there is no template to write. It is the library's long-text editor and the first whose commit is explicit: a panel with Cancel and Apply, because enter has to stay a newline and blur has to stay harmless.

1. Declaring the column

One meta.ngeEdit entry. The cell shows read-only truncated text until it is activated, then the panel opens with the caret already in the field.

2. ⚠️ getRowId stops being optional

The moment any column opts into editing, the config must identify its rows. This is the one mistake in this story that looks like data corruption rather than a bug, so the library throws in dev instead of degrading.

3. The options a column can declare

All optional. They ride editorInputs rather than a top-level meta key, because a cell context carries a column id and no column — an editor cannot read column meta by any route. ngeCellTextareaEdit() exists because that bag is Record<string, unknown> and the adapter drops a misspelled key in silence; going through the helper turns it into a compile error.

{{ optionsSnippet }}

4. The host's side — the table proposes, the host applies

Pressing Apply emits an edit-intent carrying columnId, rowId, value and previousValue. Nothing changes until you apply it and hand new data back in.

edit-intent shares its payload shape with fill-intent (ARCH-271), so one applyPatches serves both — and they stay two separate kinds, so a host may accept one and decline the other.

{{ hostSnippet }}

5. When to reach for something else

This editor is a default, not a fixture. A [ngeCell] template for the same column shadows it entirely — the slot registry consults projected templates first — so a consumer who needs a resize grip, markdown, autosize-to-content or per-column validation writes their own control and this is simply never reached. That seam is what keeps the library's own editors small.

For short single-line values use <nge-cell-input>; for a fixed set of choices use <nge-cell-select>. Reach for this one when the column holds prose.
