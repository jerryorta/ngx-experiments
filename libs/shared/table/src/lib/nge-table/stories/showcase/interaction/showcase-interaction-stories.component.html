NgeTable — Showcase (Interaction)

Every shipped feature, on one table: 10,000 virtualized rows, columns pinned on both edges with drag-to-resize, sorting and zebra striping, row selection behind a swappable control, cell-range selection with column selection and the fill handle, cell highlighting with CSV export of everything or of the marked cells alone, a chart behind the scroll-settle gate, all four inline editors, and row expansion into a detail band holding a second chart that animates open. The Controls panel below flips the six config-gated CAPABILITIES; cell highlighting and cell range are always present — they are construction-time providers, not a runtime toggle.

Driving state from OUTSIDE the table

A gesture is only half of the controlled-state contract. These buttons write state the way a saved view would be restored — and host-pushed state is deliberately silent: it emits no NgeTableEvent, so none of these clicks appear in the demo's own event log above.

The whole controlled-state contract
