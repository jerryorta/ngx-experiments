NgeTable — Column Selection Usage

Column selection is one more projected template on top of provideNgeCellRange(). There is no enableColumnSelection flag, no second provider, and no second state slice — a selected column is an ordinary NgeCellRange whose row endpoints are null. No example below imports @tanstack/*.

1. The whole integration

The providers you already have for cell ranges, plus a header-overlay template. The handle binds its own listeners rather than riding the delegated table root, so the two templates are independently optional — either alone works. 

@Component({{ "{" }}
  providers: [provideNgeCellRange()],
  imports: [
    NgeTableComponent,
    NgeTableSlotDirective,
    NgeRangeOverlayComponent,
    NgeRangeColumnHandleComponent,
  ],
{{ "}" }})
export class MyTableComponent {{ "{" }}
  readonly rows = myRows;
  readonly state = signal(createNgeTableState());

  config = createNgeTableConfig<Row>({{ "{" }}
    columns: MY_COLUMNS,
    data: myRows,
    // ⚠️ Mandatory once anything marks a row, a cell, or a column.
    getRowId: row => row.id,
  {{ "}" }});
{{ "}" }}
<nge-table [config]="config" [(state)]="state">
  <ng-template ngeTableSlot="cell-overlay" [ngeTableSlotOf]="rows" let-cell>
    <nge-range-overlay [cell]="cell" [state]="state()" />
  </ng-template>

  <ng-template ngeTableSlot="header-overlay" [ngeTableSlotOf]="rows" let-header>
    <nge-range-column-handle [header]="header" [state]="state()" />
  </ng-template>
</nge-table>

2. What a selected column looks like in state

Two null row endpoints, and no row id anywhere. Membership is answered by a predicate against the current view rather than by a stored list, so the object is the same size for twelve rows as for ten thousand. 

// state.ngeRange.ranges — one whole column
[
  {{ "{" }}
    anchorColumnId: 'status',
    anchorRowId: null,      // ← "the first row of the view"
    focusColumnId: 'status',
    focusRowId: null,       // ← "the last row of the view"
  {{ "}" }}
]

3. Selecting a column in code

NgeRangeBridge is the ergonomic path — the same methods the strip calls, by column id. Inject it from the component that carries the providers. 

private readonly range = inject(NgeRangeBridge);

selectAmountColumn(): void {{ "{" }}
  this.range.startColumn('amount');
{{ "}" }}

selectThroughQuantity(): void {{ "{" }}
  this.range.extendToColumn('quantity');   // span from the anchor column
{{ "}" }}

addOrDropOwner(): void {{ "{" }}
  this.range.startColumn('owner', {{ "{" }} additive: true {{ "}" }});   // toggles
{{ "}" }}

Or write the state directly, with no gesture at all — the host owns it either way. Pushed state is deliberately silent: it emits no NgeTableEvent, so restoring a view never replays as user activity. 

this.state.update(state => ({{ "{" }}
  ...state,
  ngeRange: {{ "{" }} ranges: [ngeWholeColumnRange('amount')] {{ "}" }},
{{ "}" }}));

4. Persisting and restoring a view

The table below was handed a saved selection at construction — no gesture has been made on it. Because a whole-column mark names no record, it survives a re-fetch that replaced every row, which is the property a materialised span cannot offer. 

// Save: the slice is plain JSON by construction.
await setDoc(viewRef, {{ "{" }} table: this.state() {{ "}" }});

// Restore: hand it straight back in.
this.state.set(saved.table as NgeTableState);

5. Exporting the selected columns

Unchanged from cell ranges, because it is the same predicate over the same slice. The export seam has never heard of column selection. 

const data = this.table().readNgeExportData({{ "{" }}
  cellPredicate: this.range.predicate(),
{{ "}" }});

// …and with the CSV formatter (ARCH-251):
const csv = formatNgeCsv(data);

6. Cell ranges without the header affordance

Leave the header-overlay template out and nothing changes for the body gesture — this is ARCH-269 exactly as it shipped. Hover a header here: there is no strip, and a header click sorts as it always did. 

<nge-table [config]="config" [(state)]="state">
  <ng-template ngeTableSlot="cell-overlay" [ngeTableSlotOf]="rows" let-cell>
    <nge-range-overlay [cell]="cell" [state]="state()" />
  </ng-template>
</nge-table>

7. Options

Column selection adds one option to provideNgeCellRange(). The other three are ARCH-269's and are unchanged. 

provideNgeCellRange({{ "{" }}
  // cmd/ctrl + Space on a focused header selects its column. Default true.
  // Scoped by FOCUS, not by engagement — so unlike Escape and cmd-A it needs no
  // opt-out on a page of several tables.
  selectColumnOnModifierSpace: true,

  clearOnEscape: true,          // ⚠️ document-level: one Escape clears every table
  selectAllOnModifierA: true,   // ⚠️ document-level, scoped by engagement
  autoScrollThreshold: 48,
{{ "}" }})

⚠️ There is no option to hide the strip. Whether the affordance exists is decided by whether you project the template, which is the same arrangement every other slot uses — a slot is a place, and what appears in it is the consumer's decision.
