NgeTable — Export & CSV (Usage)

Exporting is two independent halves. readNgeExportData() is a seam in the library — a pure read over the processed row model that produces one neutral shape and knows no output format at all. toNgeCsv() is an addon over that shape — a plain function that knows CSV and nothing else. Adding XLSX or JSON later is a second addon, not a change to the seam.

⚠️ No example on this page imports @tanstack/*. That insulation is what keeps a future engine migration internal to the library.

1. Read the table, write a CSV

readNgeExportData() is an ordinary method on <nge-table>, so an application reaches it through a viewChild without naming an engine type. The result goes straight to the formatter. 

private readonly table = viewChild.required<NgeTableComponent<Row>>('table');

download(): void {{ "{" }}
  const data = this.table().readNgeExportData();
  const csv = toNgeCsv(data);

3. formatted for a person, raw for a machine

A column says how it reads through its own namespaced meta key. The fixture's currency and date columns declare one; the other five fall back to String(value). ⚠️ Keeping that formatter in step with the column's cell renderer is the consumer's job — the library sees a template on one side and a function on the other and cannot compare them.

4. Delimiter, header, line ending, byte-order mark

The defaults are RFC 4180: comma-separated, CRLF between records, a header row, no BOM, and no trailing separator. ⚠️ Quoting is decided against the configured delimiter — under ; a value containing a comma is left bare, because a comma is then just an ordinary character. 

toNgeCsv(data, {{ "{" }}
  byteOrderMark: true,   // Excel on Windows needs it to read UTF-8 as UTF-8
  delimiter: ';',
  header: false,
  newline: '\n',
  values: 'raw',
{{ "}" }});

5. Which rows — slice

all covers every row that survived the active filters, in the current sort order. page covers only the rendered ones — identical to all until pagination is switched on, which is the correct degradation rather than a special case. selected covers the selected rows, still filtered and still sorted. 

toNgeCsv(table.readNgeExportData({{ "{" }} slice: 'selected' {{ "}" }}));

6. Exporting only the highlighted cells

The composition, and the whole of it. cellPredicate is deliberately anonymous in both directions: the export seam takes a NgeCellContext → boolean and never learns highlighting exists, and the highlight addon supplies one and never learns exporting exists. They meet on the table instance and nowhere else. The formatter, for its part, sees only the shape that comes back.

Supplying a predicate narrows the export both ways — a row with no surviving cell is dropped and a column with no surviving cell leaves columns — so a highlighted-cell CSV needs no row or column bookkeeping of its own. Mark some cells and export. 

const csv = toNgeCsv(
  table.readNgeExportData({{ "{" }} cellPredicate: highlight.predicate() {{ "}" }})
);

7. Downloading is the host's concern

toNgeCsvBlob is as far as the formatter goes. The object URL, the anchor, the filename and the revoke are application decisions — a library reaching for document here would stop working under SSR for no benefit. 

const url = URL.createObjectURL(toNgeCsvBlob(data, {{ "{" }} byteOrderMark: true {{ "}" }}));
const link = document.createElement('a');

link.download = 'export.csv';
link.href = url;
link.click();
URL.revokeObjectURL(url);

8. Formula injection — escapeFormulas

⚠️ Excel and Sheets read a field beginning =, +, -, @, a tab or a carriage return as a formula and evaluate it on open. The value in that cell usually came from whoever typed into the source system, so an export is a way to run their text as code on the reader's machine. escapeFormulas: true prefixes such a field with ' — Excel's own text marker, invisible in the rendered cell and honoured by Sheets.

It is off by default, and the default is the decision. Escaping alters the user's data: the field no longer round-trips, and anything parsing the CSV as data rather than opening it as a spreadsheet sees the '. A library should not make that trade without being asked — so turn it on for anything a person will open, and leave it off for anything another program will parse.

⚠️ The guard is prefix and not-a-number, which is the whole difficulty: - and + are also how every negative and signed number begins, so a naive prefix test corrupts an entire currency column while the file still opens. Note the last row below staying bare. The cost lands instead on a formatted negative such as -$1,234.50, which is not a plain number and is escaped — it was already text a spreadsheet could not sum. 

toNgeCsv(data, {{ "{" }} escapeFormulas: true {{ "}" }});
escapeFormulas: false (default)
{{ unescapedCsv }}
escapeFormulas: true
{{ escapedCsv }}

9. What this addon deliberately does not do

There is only one formatter. A second format is a second addon over the same neutral shape, never a branch inside this one and never a change to the seam — that separation is the property the extensibility gate exists to verify.

⚠️ The read is eager and proportional to rows × columns: the 10,000-row fixture (70,000 cells) takes roughly 170–230 ms in one synchronous pass. That is a visible pause rather than a freeze, and it is the documented limit — a host exporting materially more should export in chunks, because the seam will not yield.
