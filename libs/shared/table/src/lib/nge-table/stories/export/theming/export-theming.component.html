NgeTable — Export & CSV (Theming)

A CSV has no rendered surface, so it has nothing to theme. It reads no CSS custom property and carries no --nge-table-* token, and a section demonstrating a token nothing consumes would render as a no-op and teach a false contract. This page therefore does the opposite of the usual theming story: it shows that theming reaches the pixels and stops there.

What is themeable here is the surface a user exports from — the table and the highlight tint that picks the cells. Both already have their own token tables in Core/Theming and Highlight/Theming; this page does not restate them.

1. Three themes, one CSV

The same config, the same seeded marks, three scoped wrapper classes re-declaring --nge-table-*. Press the button and read the three outputs: they are byte-identical, because the formatter reads host-owned state and column values and never asks the DOM what anything looked like.

That is not a happy accident — it is the same property that makes a cell an arbitrary render target. A cell may be a chart or an input, so there is no general way to ask one what it displayed; exported text comes from meta.ngeExport.format instead. Styling has nowhere to enter.

2. Where an export's appearance actually comes from

Three knobs decide how an export reads, and none of them is a CSS token. Reaching for a stylesheet to change any of these is the mistake this section exists to prevent.

What you want to change Where it lives
How a column's text reads (currency, dates) columnDef.meta.ngeExport.format — TypeScript, on the column
Human text vs machine values toNgeCsv(data, {{ "{" }} values {{ "}" }}) — a formatter option
Delimiter, header, line ending, byte-order mark NgeCsvOptions — a formatter option
Which cells are included cellPredicate / slice — the export seam
How the table and its highlights look --nge-table-* — and it stops there, as section 1 demonstrates

3. The dark section is the shape a real bridge takes

Six persona themes bridge --nge-table-* (ARCH-277), so the Storybook theme toolbar does move this table — switch to a concierge, cognition or Media Workbench theme to watch it follow. A real bridge looks exactly like the .theme-dark wrapper class in this story's SCSS, only scoped to the domain's theme class instead.

⚠️ Restate every surface in a dark bridge rather than letting any inherit — the pinned surfaces especially, which are opaque by requirement, so a missed one shows up as a pale rectangle punched through a dark table. ⚠️ And note the two geometry tokens --nge-table-row-height / -header-height are unreachable from a wrapper class whenever the config carries them: createNgeTableConfig() always fills them in and the component writes them inline on the host, where they outrank any class.
