NgeTable — Export & CSV (Interaction)

The CSV writer is an addon — a plain function over the neutral export shape, with no table instance, no Angular, and no knowledge that highlighting exists. Highlighted-cell export is therefore not a feature anybody built: it is what happens when the highlight addon's predicate is handed to the export seam and the result is handed to the formatter. That is the epic's extensibility gate (ARCH-251). Click cells to mark them, shift-click to extend a block, then export.

The Storybook controls drive the formatter's whole option surface — delimiter, header, formatted / raw, the byte-order mark, and formula escaping. Change one and every CSV below re-renders without the table being read again.

1. Highlight cells, export them as CSV

Three pieces, none of which imports another. The highlight addon supplies a NgeCellContext → boolean; the export seam takes it as an anonymous cellPredicate and narrows both ways — a row with no surviving cell is dropped, and a column with no surviving cell leaves the header; the formatter reads what comes back. Export everything for the contrast. 

const data = table.readNgeExportData({{ "{" }} cellPredicate: highlight.predicate() {{ "}" }});
const csv = toNgeCsv(data);

2. formatted vs raw

Every exported cell carries both readings, and one CSV cannot be both. formatted is what a person reads — the column's own meta.ngeExport.format, so Amount comes out as $1,802.44 and has to be quoted because it carries a comma. raw is what a machine reads — the same cell is 1802.44, bare, and still summable in a spreadsheet. Which one is wanted is a property of the destination, not of the table.

Export something in section 1 first. Note that the quoting is conditional: an amount under a thousand carries no comma and so needs no quotes.

@if (exportData()) {
values: 'formatted'
{{ formattedCsv() }}
values: 'raw'
{{ rawCsv() }}
} @else {

Export something in section 1 to populate this.

}

3. Quoting follows the delimiter, not a literal comma

RFC 4180 says a field is quoted when it contains the delimiter, a double quote, or a line break — and the delimiter is whichever one was configured. Testing for a comma instead is the classic bug in a CSV writer, and it fails in both directions at once: a comma gets needlessly quoted (harmless) and a semicolon is left bare, which silently splits one field into two on the reader's side.

The same export below, written both ways. Under , the currency column is quoted; under ; it is not, because a comma is now just an ordinary character.

@if (exportData()) {
delimiter: ','
{{ commaCsv() }}
delimiter: ';'
{{ semicolonCsv() }}
} @else {

Export something in section 1 to populate this.

}

4. The CSV reflects what the user currently sees

The export reads the processed row model — post-filter, post-sort, in the column order and visibility on screen. So a sort reorders the CSV and hiding a column drops it, without a line of the formatter knowing that sorting or visibility exist. Sort, hide Quantity, then re-export and read the records.

@if (viewCsv()) {
CSV of the current view
{{ viewCsv() }}
}

5. A ragged block comes out rectangular

Mark cells in different columns on different rows, then export. The narrowed shape is deliberately ragged — each row carries only its surviving cells — but the CSV is rectangular, because the formatter re-aligns every row against the export's columns and writes an empty field where a row has no cell. That is why each cell carries its columnId, and it is what lets highlighted-cell export need no row or column bookkeeping of its own.

@if (raggedCsv()) {
CSV
{{ raggedCsv() }}
}

6. Handing it to the host

toNgeCsvBlob is where the formatter stops. The object URL, the anchor, the filename and the revoke are all application decisions — a library reaching for document would stop working under SSR for no benefit. ⚠️ Turn the byte-order mark control on for anything a user will open by double-clicking: without one, Excel on Windows reads a UTF-8 file as the ambient code page and every non-ASCII character arrives mojibake. 

const url = URL.createObjectURL(toNgeCsvBlob(data, {{ "{" }} byteOrderMark: true {{ "}" }}));
const link = document.createElement('a');

link.download = 'export.csv';
link.href = url;
link.click();
URL.revokeObjectURL(url);

7. Formula-injection escaping

⚠️ Excel and Sheets evaluate a field beginning =, +, -, @, a tab or a carriage return as a formula on open, so an export can run the source system's text as code on the reader's machine. The escapeFormulas control prefixes such a field with '. It is off by default because escaping alters the user's data — the field no longer round-trips.

⚠️ Toggling the control against the tables above changes nothing: no fixture value is formula-shaped, so the flag is a no-op over ordinary data and a host can adopt it without auditing its columns. This section supplies its own values so the toggle has something to do. Watch the last row — an ordinary negative that a prefix-only check would corrupt, and the reason the guard is prefix and not-a-number.

escapeFormulas: {{ escapeFormulas() }}
