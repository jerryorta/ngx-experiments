NgeTable — Zebra Striping (Theming)

Striping has exactly one themeable token, --nge-table-row-surface-alt. There is no theme field on NgeTableConfig — the table themes through CSS custom properties only, so every section below is one scoped wrapper class re-declaring the property, which is what a consumer writes. All six persona themes bridge this token onto their own surface-container-low tier.

1. The library default

#fafafa against a #ffffff surface — deliberately faint. A stripe is a reading aid, and one strong enough to notice on its own is strong enough to compete with the marks that carry meaning. 

// _table-tokens.scss
--nge-table-row-surface-alt: #fafafa;

2. A stronger stripe

Raise the contrast for a dense table read at a distance. Note the ceiling: past a certain strength the stripe starts reading as a state rather than as a ruler, and a user begins wondering what the shaded rows have in common. 

.theme-strong {{ "{" }}
  --nge-table-row-surface-alt: #eceff4;
{{ "}" }}

3. A tinted stripe

Nothing requires the alternate surface to be grey. A low-saturation tint of the domain's own accent keeps the table looking like the rest of the product, and is the shape most of the theme bridges take. 

.theme-tinted {{ "{" }}
  --nge-table-row-surface-alt: #f2f6fc;
{{ "}" }}

5. The stripe still loses to a themed mark

Both the alternate surface and the selected surface are themed here, and the selected rows still read as selected — one of them striped, one not, and indistinguishable from each other. The stripe never declares background; it only changes the value the row's background resolves through, so a mark cannot be out-ranked by theming it wrong. 

.theme-marked {{ "{" }}
  --nge-table-row-surface-alt: #eceff4;
  --nge-table-row-surface-selected: #d7e8fb;
  --nge-table-selection-accent: #1565c0;
{{ "}" }}

6. The pinned lanes, and why they must stay opaque

A pinned lane is position: sticky and scrolls over the center lane, so its surface has to be opaque. The alternate surface reaches the lanes by inheritance, which is what keeps a striped row one continuous band — but it means a translucent value for this token would let the center cells bleed through the pinned lanes as they pass. Theme it with an opaque colour.

Scroll horizontally to check the seams. 

.theme-pinned {{ "{" }}
  --nge-table-row-surface-alt: #eef2f7;   // opaque, not rgba(…, .5)
  --nge-table-pinned-surface: #ffffff;
{{ "}" }}

7. Dark

The shape a domain's --nge-table-* bridge takes. Every surface is restated rather than left to inherit — the pinned surfaces especially, since a missed one shows up as pale rectangles punched through a dark table. In dark themes the alternate row usually goes lighter than the base surface, the reverse of the light-mode direction. 

.theme-dark {{ "{" }}
  --nge-table-surface: #16181d;
  --nge-table-surface-variant: #22252c;
  --nge-table-row-surface-alt: #1c1f25;
  --nge-table-row-surface-hover: #262a32;
  --nge-table-pinned-surface: #16181d;
  --nge-table-pinned-header-surface: #22252c;
  --nge-table-on-surface: #e4e6ea;
  --nge-table-on-surface-variant: #a4a9b4;
  --nge-table-header-on-surface: #e4e6ea;
  --nge-table-border-color: #2c3038;
  --nge-table-header-border-color: #3a3f49;
{{ "}" }}

8. What is and is not themeable here

Four tiers, and striping adds its one token to the first of them.

  • Read from CSS — --nge-table-row-surface-alt, alongside the surfaces, content, borders, header band, pinning, typography and mark tokens. Set them from a wrapper class.
  • Overwritten inline by the component — --nge-table-row-height / -header-height, whenever the config carries them. createNgeTableConfig() always fills them in, and applyGeometry then writes them inline on the host where they outrank any class.
  • Mirrored in TypeScript — the --nge-table-column-*-width family and --nge-table-selection-column-width. The resize clamp and the selection column's size read NGE_TABLE_DEFAULTS; the knob that works is NgeTableConfig.
  • Never yours to set — the --nge-table-internal-* family, which now includes --nge-table-internal-row-surface: the table writes it per row to pick the zebra surface. Setting it from a theme would stripe every row at once, which is why the token a theme does own is --nge-table-row-surface-alt.
