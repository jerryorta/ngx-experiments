ARCH-293's acceptance criterion as a number: a scripted scroll with editable columns present stays inside ARCH-289's frame budget, measured with the identical harness on the identical geometry — the same seven fixture columns, 40px rows, 240px steps.

⚠️ The always-live boolean column is the honest subject. Activation means an activated column builds no control at all while nobody is editing, so measuring only those would measure almost nothing and report a pass. Active is alwaysLive, so every rendered row really does construct a control — the worst case a consumer can configure.

⚠️ Take both readings in one session. Run with the toggle on, then off, twice each. The noise floor is not a constant — the baseline's own runs spread 1.8% warm and 4.2–4.8% shortly after a cold rebuild — so a figure from another day attributes the machine's mood to the editors.
