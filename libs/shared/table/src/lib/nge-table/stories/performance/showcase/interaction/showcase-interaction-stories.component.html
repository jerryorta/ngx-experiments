4. What each number is for

Dropped is the one that means "it stuttered": frames past 1.5× this display's own measured frame interval, so a missed vsync rather than an assumed 60Hz. p95 sits beside worst frame because one stall is ordinary — a collection, the browser doing something else — while a p95 well above the frame interval means most frames are late, which is what a person actually perceives.

Rows built is the one to watch, exactly as in the baseline. It counts row elements the browser had to construct during the run, and a window slide pays that cost whatever eleven columns and twelve features a row happens to carry — that is the whole reason it holds at 357 regardless of which of the twelve are switched on.

To first chart and worst frame in the settle-burst readout are the numbers the scroll benchmark structurally cannot produce: the moment the one deferred feature — the chart — actually pays its cost, which is at rest, never mid- scroll.

⚠️ None of the above says which of the twelve features costs what. That question belongs to the eleven sibling stories under Performance/, each measured against the same baseline the same way. This story only answers: with everything on, does the table still fit inside a frame budget.
