NgeTable — Fill Handle Theming

There is no config.theme. The handle themes through --nge-table-fill-* custom properties, so every section below is one scoped wrapper class — the same thing a consuming app writes. Each table is seeded with a selection so the grip is visible without a gesture; the pending outline is the one thing no seed can show, and section 5 says so.

1. The defaults, with nothing declared

Every token carries a literal fallback at its use site, so the handle renders correctly with no theme applied and adds nothing to _table-tokens.scss — editing that partial would be a core edit. The grip sits at the trailing edge of the block's last cell.

2. A larger target

The grip is 10px square by default. Enlarging it makes it easier to hit at the cost of covering more of the cell it sits in — a real trade rather than a free win, since the cell beneath it still has content to show. 

.large-grip {{ "{" }}
  --nge-table-fill-handle-size: 14px;
  --nge-table-fill-handle-radius: 7px;
{{ "}" }}

3. A branded accent

The grip and the pending region carry a domain's colour, alongside ARCH-269's range tokens that paint the selection they extend from. 

.theme-branded {{ "{" }}
  --nge-table-fill-handle-color: #7c3aed;
  --nge-table-fill-target-outline: #7c3aed;
  --nge-table-fill-target-surface: #f5f3ff;

  // ARCH-269's tokens, painting the source block.
  --nge-table-range-surface: #ede9fe;
  --nge-table-range-outline: #c4b5fd;
{{ "}" }}

4. Dark

The shape a domain's --nge-table-* bridge will take. The grip's outline token matters more here than anywhere: it is what keeps a small dark square legible against a dark cell.

5. The pending region — visible only under a gesture

⚠️ Drag the grip on the table below to see this section at all. The pending outline exists only while a pointer is down: the target is cleared the moment a drag ends, so no seeded state can produce it and a screenshot of this section shows nothing unusual. 

.theme-pending {{ "{" }}
  --nge-table-fill-target-surface: #fefce8;
  --nge-table-fill-target-outline: #ca8a04;
{{ "}" }}

6. No grip to theme

This table's selection is a whole column, which has null row endpoints — it names no record, so it has no corner. There is no grip here at any colour, and no token brings one back.

7. The token surface

--nge-table-fill-handle-size        10px      ← the grip, square
--nge-table-fill-handle-radius      2px
--nge-table-fill-handle-color       #1d4ed8
--nge-table-fill-handle-outline     #ffffff   ← keeps it legible on any cell
--nge-table-fill-target-surface     #eff6ff   ← the pending region
--nge-table-fill-target-outline     #1d4ed8

None are in _table-tokens.scss — an addon that edited the core token partial would not be an addon. Every use site carries its literal fallback instead.
