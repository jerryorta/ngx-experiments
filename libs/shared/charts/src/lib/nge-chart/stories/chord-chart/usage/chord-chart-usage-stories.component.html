Chord Chart - Usage Examples

A circular or linear diagram of weighted relationships between a fixed set of nodes. One layer folds three catalog entries into one primitive via layout + linkMark — the Chord Diagram, the Non-ribbon Chord, and the Arc Diagram. Data is a single NgeGraph object ({{ "{" }} links, nodes? {{ "}" }}), not an array — the same shape the sankey layer uses.

1. Chord Diagram

The defaults — layout: 'circular', linkMark: 'ribbon'. Every node becomes a ring arc sized by its total flow; every connection is a filled ribbon between two arcs. link.opacity defaults to 0.4 so crossings stay legible. 

graph = {{ "{" }}
  links: [
    {{ "{" }} source: 'Northeast', target: 'Southeast', value: 420 {{ "}" }},
    {{ "{" }} source: 'Southeast', target: 'Northeast', value: 95 {{ "}" }},
    // ...
  ],
{{ "}" }};

config = createChordChartConfig({{ "{" }}
  data: this.graph,
  showLabels: true,
{{ "}" }});

<nge-chart [config]="config" />

2. Non-ribbon Chord

linkMark: 'edge' keeps the same ring but strokes a thin curve tracing each ribbon's centreline instead of filling it — trading the ribbon's volume for legibility of exactly which nodes connect. 

config = createChordChartConfig({{ "{" }}
  data: graph,
  linkMark: 'edge',
  showLabels: true,
{{ "}" }});

3. Arc Diagram

layout: 'linear' abandons the ring for a horizontal baseline: nodes become circles sized by their total flow, connections become stroked semicircular arcs above the baseline whose stroke-width is proportional to the link's own value. 

config = createChordChartConfig({{ "{" }}
  data: graph,
  layout: 'linear',
  showLabels: true,
{{ "}" }});

4. Node Labels

showLabels draws a label off each node — past the ring in circular layout, beneath the circle in linear layout. labelPadding is the gap between the mark and its label.

5. Ring Sizing

innerRadius (circular layout only) is a RATIO of the outer radius setting how thick the arc band reads — 0.75 here leaves more room for the ribbons than the 0.9 default. radiusRatio instead scales the WHOLE ring down, opening up space around it without changing the band's proportions.

innerRadius: 0.75
radiusRatio: 0.7

6. Directed vs. Merged Ribbons

directed: false (default) merges A→B and B→A into ONE ribbon with asymmetric ends; directed: true draws them as two distinct ribbons. Compare Northeast ↔ Southeast (420 vs 95) in each — merged, it is one ribbon pinched narrow at the Southeast end; directed, it is two separately-coloured ribbons. 

config = createChordChartConfig({{ "{" }}
  data: graph,
  directed: true,
  showLabels: true,
{{ "}" }});
directed: false (default)
directed: true

7. Sort Subgroups

sortSubgroups orders the ribbons WITHIN each node's arc by value instead of leaving d3-chord's own order — 'ascending' here walks each arc from its smallest connection to its largest.

8. Tooltips

Hover a node's arc or circle. The default formatter reports the node's laid-out flow total, so a node the caller gave no value still shows the number the layout summed for it.

9. Click Handling

onClick receives the node datum — carrying its summed flow as value — plus its index among the drawn nodes.

Last clicked: {{ lastClicked() }}

10. Dynamic Data with Signals

Hold the graph in a signal() and derive the config with computed() — the layer recomputes the matrix and every arc / ribbon tweens to its new geometry.
