Chord Chart - Theming Examples

The theme.chord slice carries three sub-slices — node, link and label. Every default is a --nge-chart-* token with a literal fallback, so a chart renders correctly with no theme applied at all.

Default Theme

No theme provided — renders on the chart's --nge-chart-* token defaults.

Custom Regional Palette

seriesColors assigns one colour per node by index. A link with no colour of its own inherits its SOURCE node's, so recolouring the nodes recolours every ribbon that leaves them.

Node Outline & Opacity

node.stroke / node.strokeWidth separate arcs that sit close together on the ring; node.opacity lets the arcs themselves read slightly translucent.

Label Typography

label.color / fontSize / fontWeight, with a wider labelPadding. The slice is theme-relative and has no colorOnDark: a chord label never sits on a mark, so it takes no on-fill contrast derivation.

Non-ribbon Chord, Themed

The straight-edge reading takes exactly the same theme.chord slice as the filled ribbons — only linkMark (geometry, not theme) differs.

Arc Diagram, Themed

A cooler palette under the linear layout — layout is geometry, not theme, so the same theme.chord shape composes with either reading.

Link Opacity Is the Load-Bearing Knob

Ribbons overlap wherever flows cross. Near-opaque, the diagram collapses into whichever ribbon paints last; too translucent and the individual flows go faint. The default 0.4 is the compromise.
