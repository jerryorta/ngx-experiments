Treemap Chart - Theming Examples

The treemap reads theme.treemap.cell for its marks and theme.treemap.label for in-cell text. Every value resolves through --nge-chart-* tokens, so a domain theme restyles the chart without touching the config.

Depth Fade — Making Nesting Visible

cell.depthFade lightens each level of nesting by that many HCL luminance units. All three charts below use a SINGLE palette colour and expose the parent band: without the fade, a branch and its children read as one blob, because the hairline stroke alone cannot carry the structure once cells get small. Note that a gapless treemap hides its parents entirely behind their children, so the fade only shows where a parent is visible — or where the tree's branches reach different depths. A node carrying its own color opts out and is drawn exactly as named.

depthFade: 0 (off)

Cell Separation

A treemap tiles its box with no gaps, so adjacent same-branch cells need a stroke to read as separate. Both charts below use padding: 0 — only the stroke differs.

Label Typography and Automatic Contrast

label.color and label.colorOnDark are the two endpoints the renderer picks between per cell, measured against that cell's own fill — which is why they default to the ABSOLUTE black / white tokens rather than theme-relative ones.

Flat Label Colour

Setting labelColor on the layer deliberately disables the contrast derivation, giving one flat colour on every cell. A per-datum labelColor still wins over it.
