Treemap Chart - Usage Examples

A treemap partitions the plot into nested cells whose area is proportional to value. It reuses the shared NgeHierarchyDatum tree — leaves carry a value, branches have theirs summed from their children.

1. Basic Treemap

The simplest form. tiling defaults to 'squarify', which drives cell aspect ratios toward 1 so areas stay comparable by eye. 

data = [
  {{ "{" }}
    label: 'Compute',
    children: [
      {{ "{" }} label: 'EC2', value: 4200 {{ "}" }},
      {{ "{" }} label: 'Lambda', value: 860 {{ "}" }},
    ],
  {{ "}" }},
  // ...
];

config = createTreemapChartConfig({{ "{" }} data: this.data {{ "}" }});

<nge-chart [config]="config" />

2. Labelled Cells

showLabels draws a label inside each cell, coloured for contrast against the cell's own fill. Cell areas span orders of magnitude, so minLabelSize drops the ones too small to seat text on either axis rather than letting it spill. 

config = createTreemapChartConfig({{ "{" }}
  data: this.data,
  showLabels: true,
  minLabelSize: 44,
  formatLabel: d => `${{ "{" }}d.label{{ "}" }} · $${{ "{" }}d.value{{ "}" }}`,
{{ "}" }});

3. Nested Proportional Area

paddingOuter insets children from their parent's edge so the parent stays visible as a container, and paddingTop reserves a strip at the top for the parent's own label. Pair it with maxLabelDepth: 1 to label the branches only. 

config = createTreemapChartConfig({{ "{" }}
  data: this.data,
  padding: 2,
  paddingOuter: 4,
  paddingTop: 18,
  showLabels: true,
  maxLabelDepth: 1,
{{ "}" }});

4. Tiling Variants

Six rectangular tilings cut the same data differently. 'squarify' optimises aspect ratio, 'binary' preserves sibling order better, and 'slice-dice' alternates direction by depth. Prefer 'resquarify' over 'squarify' for live data — it keeps cells in place across value updates instead of reshuffling.

5. Convex Treemap (Voronoi)

tiling: 'voronoi' swaps the rectangles for a weighted-Voronoi partition of straight-edged convex polygons — the reading shifts from strict nesting toward grouping and adjacency. It is an iterative solve rather than a closed-form layout, so it starts from randomly-placed sites: seed fixes the arrangement so the same data always draws the same picture. Change the seed to shop for a nicer one. 

config = createTreemapChartConfig({{ "{" }}
  data: this.data,
  tiling: 'voronoi',
  seed: 7,
  showLabels: true,
  maxLabelDepth: 1,
{{ "}" }});

6. Tooltips

Hover a cell for its label and value. A branch reports its SUMMED aggregate, so the formatter never sees an undefined value on an internal node.
