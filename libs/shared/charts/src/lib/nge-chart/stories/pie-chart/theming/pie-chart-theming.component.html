Pie Chart - Theming Examples

Slice colours resolve per-datum color → the layer's seriesColors → the theme slice.colors palette (by input index). Override theme.pie.slice.colors to reskin the whole cycle, or set stroke / strokeWidth / opacity for separators and transparency. Opt-in on-arc labels take their own theme.pie.label slice. Light / dark is handled by the review container.

Default Theme

No theme provided — uses the built-in --nge-chart-* token palette, which adapts to the surrounding light / dark surface.

On-arc Label Styling

Turn labels on with showLabels: true, then restyle them through theme.pie.label — color, colorOnDark, fontSize and fontWeight. The colour defaults read the --nge-chart-black / --nge-chart-white tokens, and the typography defaults read --nge-chart-label-font-size / --nge-chart-label-font-weight (10px, weight 600). Black and white are absolute tokens, not theme-relative ones, on purpose: an on-arc label sits on a saturated slice fill rather than on the page surface, so it must not track --nge-chart-on-surface, which goes near-black in light themes and left labels unreadable on the palette.

The two colours are the endpoints of the automatic on-fill contrast described in the next section: color is used on a light slice, colorOnDark on a dark one. Set both to the same value — as the restyled chart below does — to pin one flat colour while still theming it.

fontSize and fontWeight accept a number (px / numeric weight, shown below) or a string passed to CSS verbatim, so a brand can point them at its own custom properties instead.

Data-driven Label Colour

A label is drawn on top of a data fill, and that fill comes from the series palette — a range. One global label colour therefore cannot be right for every mark: white reads on a deep blue slice and vanishes on a pale yellow one. The label colour is resolved per slice through four rungs, highest priority first:

  1. per-datum labelColor on the data point;
  2. layer-config labelColor (one flat colour for the whole layer);
  3. derived from the fill — theme.pie.label.colorOnDark when the slice is perceptually dark, else theme.pie.label.color;
  4. theme.pie.label.color when the fill cannot be measured.

Both charts below use the SAME six-colour palette, deliberately spanning the full luminance range from #0D47A1 to #E0F7FA. The left one derives per slice (the default — nothing to configure); the right one pins labelColor: '#ffffff', which switches derivation off and reproduces the unreadable-label ceiling on the two palest slices.

Outside Label Styling (labelOutside + leaderLine)

labelPosition: 'outside' reads a separate theme slice, theme.pie.labelOutside — not theme.pie.label. The split is structural, not cosmetic: the two placements have opposite backdrops, so they need opposite colour rules. An on-arc label sits on a saturated slice fill, so label is an absolute --nge-chart-black / --nge-chart-white pair that automatic contrast picks between per slice. An outside label sits on the page surface, so labelOutside tracks the theme-relative --nge-chart-on-surface instead.

Note what labelOutside does not have: a colorOnDark. That absence is the mechanism — with no contrast pair to pick between, the resolver short-circuits to color, so an outside label can never derive from a fill it is not drawn on. Both explicit overrides still work. leaderLine styles the connectors, which appear only on labels the collision pass displaced.

Default — on-surface + muted outline
Restyled labelOutside + leaderLine

The slices are independent. Below, the on-arc slice is restyled to 20px yellow while the chart renders outside labels — and nothing changes, because outside labels never read that slice. Overriding one placement cannot leak into the other.

A per-datum labelColor still wins in outside mode — Savings below carries its own colour while the rest take labelOutside.color.
