Tree Chart - Usage Examples

A hierarchy drawn as a link diagram — the only reading that draws the parent-child relationship itself, where the sunburst nests it as angle and the treemap as area. Two orthogonal options cover four catalog entries: alignLeaves gives the Dendrogram, layout gives the Radial Convergence, and orientation + linkShape give the Organisational Chart and the Mind Map.

1. Mind Map (default)

A tidy tree growing left to right with curved edges. Each node sits at its own depth, so position reads as distance from the root. 

data = [
  {{ "{" }}
    label: 'Drinks',
    children: [
      {{ "{" }} label: 'Coffee', children: [/* … */] {{ "}" }},
      {{ "{" }} label: 'Water', value: 2 {{ "}" }},
    ],
  {{ "}" }},
];

config = createTreeChartConfig({{ "{" }}
  data: this.data,
  showLabels: true,
{{ "}" }});

2. Dendrogram — alignLeaves

The same data with every leaf pushed onto the outer edge regardless of its depth, so the leaf set reads as a scannable list. The trade is real: alignment buys the list and gives up showing depth by position — compare Espresso here against example 1. 

config = createTreeChartConfig({{ "{" }}
  data: this.taxonomy,
  alignLeaves: true,
  showLabels: true,
{{ "}" }});

3. Organisational Chart — orientation + linkShape: 'elbow'

Not a layout of its own: the same tidy tree drawn top-down with right-angle edges, which is what makes a connection read as a reporting line rather than a flow. Every edge at one level turns on the same line, so siblings read as a bracket. 

config = createTreeChartConfig({{ "{" }}
  data: this.org,
  orientation: 'top-bottom',
  linkShape: 'elbow',
  showLabels: true,
{{ "}" }});

4. Radial Convergence — layout: 'radial'

The root moves to the centre and depth grows outward, which buys room: a radial tree seats the same leaf count in a circle rather than a strip, so a wide hierarchy stops running out of breadth. radiusRatio scales the whole diagram inside its plot. 

config = createTreeChartConfig({{ "{" }}
  data: this.org,
  layout: 'radial',
  alignLeaves: true,
  showLabels: true,
{{ "}" }});

5. Capping depth — maxDepth

Draw only the top levels of a deep hierarchy. The remaining levels spread across the whole plot rather than leaving a gap where the pruned depth was, and a node whose children are hidden still reports its full subtree total to formatLabel and the tooltip. 

config = createTreeChartConfig({{ "{" }}
  data: this.org,
  maxDepth: 1,
  showLabels: true,
{{ "}" }});

6. Click Handling

onClick receives the node datum carrying its summed subtree value, so an internal node reports its aggregate rather than undefined. 

config = createTreeChartConfig({{ "{" }}
  data: this.org,
  onClick: (event) => this.lastClicked.set(`${{ "{" }}event.data.label{{ "}" }}`),
  showLabels: true,
{{ "}" }});

7. Tooltips

Hover a node for a bubble anchored above its circle. Useful precisely when showLabels is off — a dense tree is unreadable with every node named, and the tooltip gives the detail back on demand. 

config = createTreeChartConfig({{ "{" }}
  data: this.org,
  tooltip: {{ "{" }}
    enabled: true,
    formatContent: (d) => ({{ "{" }} label: d.label, value: `${{ "{" }}d.value{{

          }} people` {{ "}" }}),

{{ "}" }});

8. Dynamic Data with Signals

Wrap the factory in a computed() so the chart rebuilds whenever the data signal changes. The join is keyed by each node's root-to-node path, so a branch that survives a data change keeps its circle and animates to its new seat instead of being redrawn.
