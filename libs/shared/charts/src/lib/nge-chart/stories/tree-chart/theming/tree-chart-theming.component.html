Tree Chart - Theming Examples

The tree layer exposes three theme slices — node, link and label. A node's colour comes from its top-level branch, so a branch and everything under it share one hue and a legend over the branches serves the whole diagram.

Default Theme

No theme provided — renders on the chart's --nge-chart-* token defaults.

Green Palette

node.colors is indexed by top-level branch, so Coffee, Tea and Water each take one entry and their descendants inherit it.

Blue Palette with Heavier Edges

link.width and link.opacity control how loudly the structure itself reads. A tree's edges never cross, so full opacity costs nothing here — unlike a force-directed network, where translucency is what keeps a dense interior legible.

Quiet Edges

The inverse emphasis: faint, thin links and outlined nodes, for when the nodes are the finding and the hierarchy is only context.

Label Typography

A tree label always sits beside its node, never on it, so the label slice is theme-relative and carries no on-fill contrast derivation — set color and it is simply used.

Dendrogram

alignLeaves with a warm palette. Aligning the leaves puts every leaf label in one column, which is what makes the list scannable.

Radial Convergence

The same theme slices apply unchanged in the radial layout — only the seating changes.

Organisational Chart

A heavier link.width suits linkShape: 'elbow': a right angle drawn thinly reads as a stray hairline rather than a reporting line.

Multiple Charts with Different Themes

One hierarchy, three palettes — each chart carries its own theme.tree, so panels on the same page can stay visually distinct.
