Parallel Coordinates - Usage Examples

One vertical axis per dimension, one polyline per record. Every axis carries its own scale, which is what lets quantities with different units — a weight in thousands beside a rating in tens — share a plot and each fill its own axis.

1. Basic Usage

The data is long: one datum per record per dimension, tied together by seriesId. The unique labels become the axes. 

data = [
  {{ "{" }} label: 'MPG', seriesId: 'Corolla', value: 27 {{ "}" }},
  {{ "{" }} label: 'Weight', seriesId: 'Corolla', value: 2130 {{ "}" }},
  {{ "{" }} label: 'Origin', seriesId: 'Corolla', value: 'Japan' {{ "}" }},
  // ...one group per record
];

config = createParallelCoordsChartConfig({{ "{" }}
  data: this.data,
{{ "}" }});

2. Colour by a Dimension

colorBy names the dimension whose value colours each line. Reach for it on any real dataset: cycling the palette by record index encodes nothing once the record count passes the palette size, whereas colouring by a dimension turns the chart into a readable comparison — here the three origins separate cleanly on weight and MPG. 

config = createParallelCoordsChartConfig({{ "{" }}
  data: this.data,
  colorBy: 'Origin',
{{ "}" }});

3. Axis Order and Subset

dimensions sets both which axes are drawn and their order. Order is a reading decision rather than cosmetics — a correlation between two dimensions is only visible when their axes are adjacent. Weight beside horsepower beside MPG puts the whole heavy-thirsty relationship in two hops. 

config = createParallelCoordsChartConfig({{ "{" }}
  data: this.data,
  colorBy: 'Origin',
  dimensions: ['Weight', 'Horsepower', 'MPG'],
{{ "}" }});

4. Curved Variant

curve: 'monotone' draws the catalog's curved parallel-coordinates variant. The vertices are unchanged — only the interpolation between axes differs, which makes individual lines easier to follow at the cost of implying values between the axes.

5. Mixed Numeric and Categorical Axes

A dimension whose values are all finite numbers gets a linear axis; any other gets a point (ordinal) axis over its categories in first-seen order. No configuration selects this — Origin is categorical, so it lands on a point axis beside its numeric neighbours.

6. Tooltip and Click Handling

Hovering a line traces it by dimming the others. Both the tooltip and the click payload resolve to the datum on the axis nearest the pointer, so pointing at a line near the weight axis reports its weight.

7. Dynamic Data with Signals

The config is a computed() over a data signal, so the chart reconciles rather than redraws — surviving records animate to their new positions. Each axis re-domains to the data it now holds.
