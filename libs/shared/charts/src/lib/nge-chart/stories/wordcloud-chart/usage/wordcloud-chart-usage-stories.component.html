Word Cloud Chart - Usage Examples

Frequency-sized text placed by a spiral layout. Each word's value maps to a font size, and the words are placed largest first along an archimedean spiral out from the centre — each taking the first position whose bounding box clears every word already placed. Placement is deterministic: the same data at the same size always draws the same picture, so a resize or theme change reflows rather than reshuffles.

1. Basic Usage

Simplest way to create a chart using createWordCloudChartConfig(). The word with the highest value is drawn at maxFontSize, the lowest at minFontSize. 

data = [
  {{ "{" }} label: 'angular', value: 120 {{ "}" }},
  {{ "{" }} label: 'signals', value: 96 {{ "}" }},
  // ...
];

config = createWordCloudChartConfig({{ "{" }}
  data: this.data,
  maxFontSize: 52,
{{ "}" }});

<nge-chart [config]="config" />

2. Scale Modes

How value maps onto the font-size range. 'sqrt' (the default) scales the word's area with its value, which stops a high-frequency outlier from swamping the cloud; 'linear' scales the height directly and so exaggerates the leader; 'log' compresses a long tail and lifts the small terms. 

config = createWordCloudChartConfig({{ "{" }}
  data: this.data,
  scale: 'linear',      // or 'sqrt' (default) | 'log'
{{ "}" }});

3. Mixed Orientation

rotations is cycled across the words by placement order, never at random — [0, 90] gives the classic mixed cloud while keeping the layout stable across re-renders. A turned word's bounding box is turned with it, so the collision pass stays honest. 

config = createWordCloudChartConfig({{ "{" }}
  data: this.data,
  rotations: [0, 90],
{{ "}" }});

4. Font Size Range

minFontSize and maxFontSize set the span the values are mapped onto. A tight range reads as a uniform tag list; a wide one makes the leading terms dominate — and packs more of the tail in, because small words fit in the gaps.

Wide — 8 to 60px

5. Colour

seriesColors cycles a palette across the words by placement order. A per-word color beats it outright, which is how a single term is singled out. The text is the mark here, so there is no separate label colour to resolve. 

config = createWordCloudChartConfig({{ "{" }}
  data: this.data,
  seriesColors: ['#1B5E20', '#2E7D32', '#4CAF50', '#81C784'],
{{ "}" }});

// or single one out, per word:
data = [{{ "{" }} label: 'angular', value: 120, color: '#D32F2F' {{ "}" }}, /* ... */];

6. Click Handling

onClick receives the datum and its placement index. 

config = createWordCloudChartConfig({{ "{" }}
  data: this.data,
  onClick: (event) => this.lastClicked.set(event.data.label),
{{ "}" }});

7. Tooltips

Hover a word for its raw value. The bubble is anchored above the word and clamped to the chart bounds.

  data: this.data,
  tooltip: {{ "{" }}

8. Formatted Labels

formatLabel changes the text that is drawn and measured. The datum's own label stays the join key, so the enter/update/exit animation is unaffected. 

config = createWordCloudChartConfig({{ "{" }}
  data: this.data,
  formatLabel: (d) => d.label.toUpperCase(),
{{ "}" }});

9. Dynamic Data with Signals

Wrap the factory in a computed() over a data signal. Words that survive a change keep their DOM node and slide to their new position; words that leave fade out. 

data = signal<NgeWordCloudDataPoint[]>([/* ... */]);

config = computed(() =>
  createWordCloudChartConfig({{ "{" }} data: this.data() {{ "}" }})
);
