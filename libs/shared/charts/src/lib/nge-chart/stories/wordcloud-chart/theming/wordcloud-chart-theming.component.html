Word Cloud Chart - Theming Examples

The layer declares ONE theme slice, wordcloud.word. The text is the mark here, so its colour comes straight from the categorical palette — there is no separate label slice and no on-fill contrast derivation to configure.

Default Theme

No theme provided — renders on the chart's --nge-chart-* token defaults.

Green Palette

word.colors is cycled across the words by placement order.

Blue Palette

A four-entry palette repeats every fourth word, which groups the cloud visually without implying a category.

Monochrome

A single colour at graded opacity leaves size alone to carry the frequency — the most honest reading of a word cloud, since colour here encodes nothing.

Typography

word.fontFamily and word.fontWeight are used to measure as well as to draw, so the layout adapts to the face rather than colliding with it. Set fontFamily on the layer config to override the theme for one chart.
