Proportional Area Chart - Theming Examples

Every colour comes from the theme.proportional slice: mark for the shapes, emptyCell for a waffle's unfilled remainder, and label for on-mark text.

Default Theme

No theme provided — renders on the chart's --nge-chart-* token defaults.

Green Palette

theme.proportional.mark.colors is cycled by top-level input index, so a four-entry palette covers four categories exactly.

Blue Palette

A monochrome ramp reads the marks as one measure.

Red Palette

Note the label colour flipping to white on the darker marks — that is the automatic on-fill contrast derivation, not a per-datum setting.

Outlined Marks

mark.stroke / mark.strokeWidth / mark.opacity — a heavier outline keeps adjacent shapes legible when they nearly touch.

Label Typography

label.fontSize / label.fontWeight. Size and weight live on the theme rung only — they do not co-vary with the fill, so there is no per-datum equivalent.

Flat Label Colour

Setting label.color and label.colorOnDark to the same value opts the whole theme out of contrast derivation — every label takes one flat colour.

Waffle — Themed Remainder

emptyCell styles the cells between the data's total and rows × columns. It is the grid's backdrop rather than a value, which is why it is a separate slice from mark.
