Proportional Area Chart - Usage Examples

One layer that encodes value as area, not length. Every mark's linear size scales as √(value / max), so a datum worth four times another draws four times its area. The mark option picks the primitive and covers the catalog's whole proportional family — waffle, proportional area, nested area and packed circles.

1. Basic Usage

Simplest way to create a chart using createProportionalChartConfig(). Marks are laid out in an evenly-spaced row and sized by area. 

data = [
  {{ "{" }} label: 'Solar', value: 120 {{ "}" }},
  {{ "{" }} label: 'Wind', value: 80 {{ "}" }},
  // ...
];

config = createProportionalChartConfig({{ "{" }}
  data: this.data,
  showLabels: true,
{{ "}" }});

<nge-chart [config]="config" />

2. Square and Half-Circle Marks

The same magnitudes drawn as a different primitive. mark: 'square' gives the Square Proportional Area; mark: 'half-circle' stands the semicircles on one baseline, which makes their relative heights easier to compare. 

config = createProportionalChartConfig({{ "{" }}
  data: this.data,
  mark: 'square',        // or 'half-circle'
  showLabels: true,
{{ "}" }});

3. Waffle Chart

mark: 'grid' draws a 10×10 grid where each cell is one percentage point. A waffle names its categories through a legend rather than on-cell text, so showLabels is ignored for this mark — pair it with extractSunburstChartLegendItems() and a <nge-chart-legend>, both of which read the same NgeHierarchyDatum[] and cycle the same palette. 

config = createProportionalChartConfig({{ "{" }}
  data: this.gridData,
  mark: 'grid',
{{ "}" }});

legendItems = extractSunburstChartLegendItems(this.gridData);

<nge-chart-legend [items]="legendItems" />
<nge-chart [config]="config" />

4. Unit Waffle

Setting valuePerCell turns the waffle into a unit chart — one cell per fixed quantity — and leaves any surplus cells empty. Here a 5×12 grid counts 60 orders. 

config = createProportionalChartConfig({{ "{" }}
  data: this.orders,
  mark: 'grid',
  rows: 5,
  columns: 12,
  valuePerCell: 1,
{{ "}" }});

5. Packed Circles

mark: 'packed' runs d3.pack() over the data and draws its leaf circles. Nesting the data groups the leaves into clusters, and every leaf inherits its top-level branch's colour. 

data = [
  {{ "{" }} label: 'Mobile', children: [
    {{ "{" }} label: 'iOS', value: 62 {{ "}" }},
    {{ "{" }} label: 'Android', value: 91 {{ "}" }},
  ] {{ "}" }},
  // ...
];

config = createProportionalChartConfig({{ "{" }}
  data: this.data,
  mark: 'packed',
  showLabels: true,
{{ "}" }});

6. Nested Proportional Area

layout: 'nested' stacks the marks concentrically on one bottom baseline, largest first — the shape to reach for when the values are subsets of one another. 

config = createProportionalChartConfig({{ "{" }}
  data: this.funnelData,
  layout: 'nested',
{{ "}" }});

7. Click Handling

onClick receives the datum and its input index. A waffle's empty remainder cells name no datum, so they never fire. 

config = createProportionalChartConfig({{ "{" }}
  data: this.data,
  onClick: (event) => this.lastClicked.set(event.data.label),
{{ "}" }});

8. Tooltips

Hover a mark for a tooltip anchored at its centroid. The formatter receives the datum with its summed magnitude, so an internal node reports its aggregate. 

config = createProportionalChartConfig({{ "{" }}
  data: this.data,
  tooltip: {{ "{" }}
    enabled: true,
    formatContent: (d) => ({{ "{" }} label: d.label, value: d.value + ' TWh' {{ "}" }}),
  {{ "}" }},
{{ "}" }});

9. Dynamic Data with Signals

Wrap the factory in a computed() and the marks grow, shrink and reflow through the shared enter/update/exit animation whenever the signal changes. 

data = signal<NgeHierarchyDatum[]>([...]);

config = computed(() =>
  createProportionalChartConfig({{ "{" }} data: this.data(), showLabels: true {{ "}" }})
);
