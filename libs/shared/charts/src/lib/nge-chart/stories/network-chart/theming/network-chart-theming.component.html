Network Chart - Theming Examples

Default Theme

No theme provided — renders on the chart's --nge-chart-* token defaults.

Green Palette

Override theme.network.node.colors. Nodes take a palette entry by index, and a link with no colour of its own inherits its source node's — so recolouring the nodes recolours the edges with them.

Blue Palette

node.stroke matters more here than in a seated layout: a force solve routinely settles two nodes into contact, and the outline is what keeps them separate.

Warm Palette

A five-entry palette cycles by node index — colors[index % length].

Link Opacity — the load-bearing knob

A network's edges cross far more often, and at more angles, than a flow diagram's. At full opacity the interior mats into one block of colour and the structure — which is the whole finding — disappears. Compare a heavy treatment against a light one.

Label Typography

theme.network.label is theme-relative and deliberately carries no colorOnDark: a network label always sits beside its node, never on it, so there is no mark fill to derive contrast against.

Hive Axis Chrome

theme.network.axis styles the spokes the hive layout draws itself. It is the one slice with no counterpart in the force layouts, which draw no axes at all.

Node Sizing is Config, not Theme

minNodeRadius / maxNodeRadius live on the layer config rather than the theme, because they map magnitude to radius — a data concern, not a palette one. A node with no value is sized by its degree.
