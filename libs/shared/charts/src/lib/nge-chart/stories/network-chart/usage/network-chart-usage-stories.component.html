Network Chart - Usage Examples

A node-link graph drawn as a graph — the layer where a node's position carries the meaning, rather than being prescribed by a ring or a column. One layout option covers four catalog entries: Network Visualisation, Sociogram, Clustered Force Layout and Hive Plot.

1. Network Visualisation (default)

A d3-force simulation settles the graph so distance approximates relatedness. The solve is seeded and run for a fixed number of steps, so the same data draws the same picture on every render and reload. 

data = {{ "{" }}
  links: [{{ "{" }} source: 'web', target: 'gateway', value: 8 {{ "}" }}, /* … */],
  nodes: [{{ "{" }} id: 'web', label: 'Web' {{ "}" }}, /* … */],
{{ "}" }};

config = createNetworkChartConfig({{ "{" }}
  data: this.data,
  showLabels: true,
{{ "}" }});

<nge-chart [config]="config" />

2. Sociogram — directed + showLabels

Not a layout of its own: a Sociogram is the same force layout drawn by the convention that makes a social graph readable — every node named, every relationship arrowheaded so its direction is visible. 

config = createNetworkChartConfig({{ "{" }}
  data: this.team,
  directed: true,
  showLabels: true,
{{ "}" }});

3. Clustered Force Layout — layout: 'cluster'

The same simulation with a per-group anchor layered on top, so nodes sharing a group gather while each cluster's interior is still shaped by the graph's own links. Set group on each node to use it. 

nodes = [
  {{ "{" }} group: 'Client', id: 'web', label: 'Web' {{ "}" }},
  {{ "{" }} group: 'Edge', id: 'gateway', label: 'Gateway' {{ "}" }},
  // …
];

config = createNetworkChartConfig({{ "{" }}
  data: {{ "{" }} links, nodes {{ "}" }},
  layout: 'cluster',
  showLabels: true,
{{ "}" }});

4. Hive Plot — layout: 'hive'

A hive plot runs no simulation at all. Nodes are assigned to radial axes by group (falling back to a degree rule when the graph names none) and ranked along their axis by magnitude, with connections bowed between axes. Position is assigned by a rule rather than discovered by relaxation — which is the whole claim of the chart type. 

config = createNetworkChartConfig({{ "{" }}
  data: {{ "{" }} links, nodes {{ "}" }},
  layout: 'hive',
  axisCount: 4,
  showLabels: true,
{{ "}" }});

5. Click Handling

onClick receives the node datum carrying its resolved magnitude, so a caller who supplied no value still reads the node's degree rather than undefined. 

config = createNetworkChartConfig({{ "{" }}
  data: this.data,
  onClick: (event) => this.lastClicked.set(`${{ "{" }}event.data.label{{ "}" }}`),
  showLabels: true,
{{ "}" }});
Last clicked: {{ lastClicked() }}

6. Tooltips

Hover a node for a bubble anchored above its circle. The formatter receives the same resolved magnitude the drawing encodes.

  data: this.data,
  tooltip: {{ "{" }}
    enabled: true,
    formatContent: (d) => ({{ "{" }} label: d.label, value: `${{ "{" }}d.value{{

7. Re-rolling the arrangement — seed

The layout is deterministic per seed. Change the seed to ask for a different arrangement of the same data — useful when a particular solve happens to cross more edges than it needs to.

seed: {{ seed() }}

8. Dynamic Data with Signals

Wrap the factory in a computed() so the chart rebuilds whenever the graph signal changes. Nodes and links animate in and out through the keyed join.
