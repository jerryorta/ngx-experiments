Sankey Chart - Theming Examples

The theme.sankey slice carries three sub-slices — node, link and label. Every default is a --nge-chart-* token with a literal fallback, so a chart renders correctly with no theme applied at all.

Default Theme

No theme provided — renders on the chart's --nge-chart-* token defaults.

Forest

A green node.colors palette. Links inherit their source node's colour, so recolouring the nodes recolours the whole diagram.

Ocean

A blue palette with node.strokeWidth: 2 — a heavier outline separates rects that share a column.

Ember

A warm palette at a higher resting opacity, so the flows read heavier.

Monochrome

A single-entry palette. Every node takes the same grey, so the flow geometry alone carries the reading.

Label Typography

label.color / fontSize / fontWeight, with a wider labelPadding. The slice is theme-relative and has no colorOnDark: a sankey label never sits on a mark, so it takes no on-fill contrast derivation.

Parallel Sets, Themed

linkShape is geometry, not theme — the straight-sided bands take exactly the same theme.sankey slice as the curved ones.

Link Opacity Is the Load-Bearing Knob

Ribbons overlap wherever flows cross. Near-opaque, the diagram collapses into whichever ribbon paints last; too translucent and the individual flows go faint. The default 0.4 is the compromise.

opacity: 0.9 — crossings lost
opacity: 0.2 — flows faint
