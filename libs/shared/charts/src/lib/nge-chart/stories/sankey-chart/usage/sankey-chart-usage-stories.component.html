Sankey Chart - Usage Examples

Weighted flow between staged nodes. One layer covers three catalog readings — the curved Sankey, the staged Alluvial, and the straight-sided Parallel Sets — via linkShape and the data's own staging. Data is a single NgeGraph object ({{ "{" }} links, nodes? {{ "}" }}), not an array.

1. Basic Sankey

Links alone are enough — the node set is derived from the endpoints in first-seen order. Ribbon thickness is the link's value; each node's height is its larger side. 

graph = {{ "{" }}
  links: [
    {{ "{" }} source: 'Salary', target: 'Net Income', value: 4800 {{ "}" }},
    {{ "{" }} source: 'Net Income', target: 'Housing', value: 2100 {{ "}" }},
    // ...
  ],
{{ "}" }};

config = createSankeyChartConfig({{ "{" }}
  data: this.graph,
  showLabels: true,
{{ "}" }});

<nge-chart [config]="config" />

2. Parallel Sets

linkShape: 'parallelogram' swaps the cubic ribbons for straight-sided bands. With categorical stages on parallel axes that is the Parallel Sets reading — boxes for the categories, parallelograms for the relations between them. 

config = createSankeyChartConfig({{ "{" }}
  data: survey,
  linkShape: 'parallelogram',
  nodeAlign: 'left',
  showLabels: true,
{{ "}" }});

3. Alluvial

No separate mode — an alluvial diagram is the base form with stages named for successive periods, so the ribbons read as cohorts moving between tiers. nodeAlign: 'left' keeps each period in its own column even when a tier has no onward flow.

4. Explicit Nodes — order, colour and display labels

Supply nodes to control ORDER (which drives palette assignment), to give a node its own color, or to show a label that differs from its id. A link with no colour of its own inherits its SOURCE node's, so a flow stays readable as coming from somewhere. 

data = {{ "{" }}
  links: budgetLinks,
  nodes: [
    {{ "{" }} id: 'Net Income', label: 'Take-home', color: '#455a64' {{ "}" }},
    {{ "{" }} id: 'Housing', color: '#c62828' {{ "}" }},
    // ...
  ],
{{ "}" }};

5. Tooltips

Hover a node rect. The default formatter reports the node's laid-out throughput, so a node the caller gave no value still shows the total the layout summed for it.

6. Click Handling

onClick receives the node datum plus its index among the drawn nodes.

7. Dynamic Data with Signals

Hold the graph in a signal() and derive the config with computed() — the layer re-lays out and the marks animate to their new geometry.
