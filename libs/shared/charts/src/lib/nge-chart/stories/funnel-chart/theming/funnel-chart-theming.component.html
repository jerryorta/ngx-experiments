Funnel Chart - Theming Examples

Band colours resolve per-datum color → the layer's seriesColors → the theme band.colors palette (by input index). Override theme.funnel.band.colors to reskin the whole cycle, or set stroke / strokeWidth / opacity for separators and transparency. Light / dark is handled by the review container.

Default Theme

No theme provided — renders on the chart's built-in --nge-chart-* token defaults, which adapt to the surrounding light / dark surface.

Palette Overrides

Provide a custom theme.funnel.band.colors array. Band input index maps to colors[index % length], so the palette cycles for any band count.

Stroke Separators — Discrete Stages

A thicker band.stroke / strokeWidth, paired with a gap, cleanly separates adjacent bands into discrete stages instead of a continuous silhouette.

Label Typography

label.color / fontSize / fontWeight style the in-band labels drawn when showLabels: true — i.e. the default labelPosition: 'inside'. Outside labels ('edge' / 'right') read the separate labelOutside slice instead, because they sit on the plot surface rather than on a band fill.

Funnel vs Pyramid

The same primitive, two shapes — swap direction (and neckRatio for a pointed apex) to move between a top-down funnel and a bottom-up pyramid.
