Funnel Chart — Labels

Every labelPosition mode side by side. Labels are opt-in via showLabels and formatted with formatLabel. Styling comes from whichever theme slice matches the placement: 'inside' reads theme.funnel.label (an absolute black / white pair, picked per band from its own fill), while 'edge' and 'right' read theme.funnel.labelOutside — those sit on the plot surface, not on a band, so they track --nge-chart-on-surface and never derive.

1. Outside labels — 'edge' vs 'right'

'edge' sets each label just outside its own band's right edge, so the labels step inward as the funnel narrows — the classic funnel annotation. 'right' pins every label to one x for a straight, aligned column. Both reserve labelGutter px off the funnel's width, because the layers group is clipped to the plot rect and a label past boundedWidth would be cut off.

labelPosition: 'edge'
labelPosition: 'right'

2. labelPosition: 'inside' — the default

Labels are centered within each band and no gutter is reserved, so the funnel keeps the full plot width. Legible while bands stay wide — note how the last band already struggles here.

3. Long stage names — why outside labels exist

Same data and formatter in both charts. Inside labels overflow their bands as soon as the text is wider than the band; the funnel has nowhere to put them. Moving the labels out resolves it without shrinking the type.

'inside' — text outgrows the bands
'edge' — readable at every stage

4. Pyramid with labels

Labels work the same for direction: 'up'. The band order is inverted (widest at the bottom, apex at the top via neckRatio: 0), and each label still tracks its own band's edge.
