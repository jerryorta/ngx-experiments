Funnel Chart - Usage Examples

Practical examples for the funnel / pyramid layer. One trapezoid-stack primitive fans out across two shapes via config: a Funnel (direction: 'down', widest at top, narrowing downward) and a Pyramid (direction: 'up' + neckRatio: 0, widest at bottom, narrowing to a point). Each datum's value maps to a proportional band width.

1. Basic Funnel

Simplest way to create a funnel using createFunnelChartConfig(). Provide an array of {{ "{" }} label, value {{ "}" }} data points — one band per point, top to bottom in input order. 

data: NgeFunnelDataPoint[] = [
  {{ "{" }} label: 'Visitors', value: 10000 {{ "}" }},
  {{ "{" }} label: 'Signups', value: 4200 {{ "}" }},
  {{ "{" }} label: 'Trials', value: 1800 {{ "}" }},
  {{ "{" }} label: 'Customers', value: 650 {{ "}" }},
];

config = createFunnelChartConfig({{ "{" }} data: this.data {{ "}" }});

2. Pyramid

direction: 'up' stacks widest-at-bottom, narrowing upward. neckRatio: 0 collapses the last band to a point — the pyramid apex. Together they turn the same primitive into an org-hierarchy / population-pyramid shape. 

data: NgeFunnelDataPoint[] = [
  {{ "{" }} label: 'Individual Contributors', value: 400 {{ "}" }},
  {{ "{" }} label: 'Managers', value: 80 {{ "}" }},
  {{ "{" }} label: 'Directors', value: 20 {{ "}" }},
  {{ "{" }} label: 'Executives', value: 5 {{ "}" }},
];

config = createFunnelChartConfig({{ "{" }}
  data: this.data,
  direction: 'up',
  neckRatio: 0,
{{ "}" }});

3. Labels with a Custom Formatter

showLabels: true draws a label centered in each band. formatLabel overrides the default (the datum's own label) — here it appends the band's raw value. 

config = createFunnelChartConfig({{ "{" }}
  data: this.data,
  showLabels: true,
  formatLabel: (d) => `${{ "{" }}d.label{{ "}" }}: ${{ "{" }}d.value.toLocaleString(){{ "}" }}`,
{{ "}" }});

4. Gap — Discrete Stages

gap defaults to 0, so bands are contiguous — a continuous funnel silhouette. A gap > 0 carves vertical spacing between bands, separating them into discrete stages. 

continuous = createFunnelChartConfig({{ "{" }} data: this.data {{ "}" }}); // gap: 0 (default)
discrete = createFunnelChartConfig({{ "{" }} data: this.data, gap: 8 {{ "}" }});

5. Left-aligned Bands

align: 'left' pins every band's left edge to x = 0 instead of centering it — useful when the funnel sits beside other left-aligned content. 

config = createFunnelChartConfig({{ "{" }}
  data: this.data,
  align: 'left',
{{ "}" }});

6. Click Handling

Provide an onClick callback in the config. The event carries the full data point for the clicked band. 

config = createFunnelChartConfig({{ "{" }}
  data: this.data,
  onClick: (event) => {{ "{" }}
    console.log('Clicked:', event.data.label, event.data.value);
  {{ "}" }},
{{ "}" }});

7. Dynamic Data via Signals

Feed a signal() into a computed() config so the funnel rebuilds whenever the underlying data changes. 

data = signal<NgeFunnelDataPoint[]>(this.conversionData);

config = computed(() => createFunnelChartConfig({{ "{" }}
  data: this.data(),
  showLabels: true,
{{ "}" }}));

randomizeData() {{ "{" }}
  this.data.set(/* re-rolled values */);
{{ "}" }}

8. Custom Series Colors

Pass a seriesColors palette — band input index maps to colors[index % length]. A per-datum color on any data point wins over the palette for that one band. 

config = createFunnelChartConfig({{ "{" }}
  data: this.data,
  seriesColors: ['#1E88E5', '#43A047', '#FB8C00', '#8E24AA'],
{{ "}" }});

9. Labels Beside the Chart

Outside labels are the classic funnel annotation, and the only readable option once bands taper toward the neck. labelPosition: 'edge' sets each label just outside its own band's right edge, so the labels step inward as the funnel narrows. 'right' instead pins every label to one x for a straight, aligned column — compare the two below. Either way the funnel is drawn into boundedWidth - labelGutter: the strip has to come out of the plot area rather than the margin, because the layers group is clipped to the plot rect and anything past boundedWidth would be cut off. Pair with neckRatio: 0 to close the funnel to a point. 

data = [
  {{ "{" }} label: 'A', value: 60 {{ "}" }},
  {{ "{" }} label: 'B', value: 20 {{ "}" }},
  {{ "{" }} label: 'C', value: 15 {{ "}" }},
  {{ "{" }} label: 'D', value: 5 {{ "}" }},
];

config = createFunnelChartConfig({{ "{" }}
  data: this.data,
  showLabels: true,
  labelPosition: 'edge',   // labels follow the taper; 'right' = aligned column
  labelGutter: 110,
  formatLabel: d => `${{ "{" }}d.label{{ "}" }}  ${{ "{" }}d.value{{ "}" }}%`,
  neckRatio: 0,
  seriesColors: ['#F9423A', '#DE2B27', '#26325B', '#BE2141'],
{{ "}" }});
labelPosition: 'edge' — follows the taper
labelPosition: 'right' — aligned column
