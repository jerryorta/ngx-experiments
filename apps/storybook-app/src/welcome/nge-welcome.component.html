An Angular design system, built in the open

Five libraries maintained as one system: a framework-free component library and the three data-presentation libraries built against its token contract. Every component here is standalone, OnPush, signal-based, and themed entirely through CSS custom properties — no Angular Material, and no third-party component dependency.

Use the theme control in the toolbar above to re-theme any story. Nothing in a story changes but the tokens.
